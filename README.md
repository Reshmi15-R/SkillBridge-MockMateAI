# Career Copilot 

A full-stack web application built by two best friends to help students prepare for interviews, improve technical skills, and track their career growth journey.

# Project Overview

Career Copilot is an interview preparation and career guidance platform that helps users:

- Practice mock interviews
- Generate interview questions
- Track preparation progress
- Upload resumes
- Get personalized career guidance
- Improve communication and technical skills

This project is being built as a learning journey to understand:

- Frontend Development
- Backend Development
- REST APIs
- Database Management
- Authentication
- AI Integration
- Full Stack Architecture



#  Goals of This Project

We started this project to:

- Learn backend development deeply
- Understand API creation and integration
- Work with databases in real-world applications
- Build a complete full-stack application
- Explore AI and agent-based workflows
- Improve teamwork and project collaboration
- Create a placement-ready portfolio project
